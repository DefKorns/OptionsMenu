# Options Menu v2.1.1

- **Open menu during games:** new toggle in Controller. Turn it off and the button combo only opens the menu from the Home screen, so you can't open it by accident mid-game. It's on by default, so nothing changes until you turn it off.

## Which file?

- `options_menu.hmod`: use this one.
- `options_menu_compat.hmod`: only if another hmod replaces the console's `libstdc++` (e.g. RetroArch 1.8.4 Xtreme SC) and the menu doesn't open with the normal build.
