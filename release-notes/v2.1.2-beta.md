# Options Menu v2.1.2-beta

Beta for testing a fix to an occasional crash right after boot.

- **Boot crash fix:** the startup tasks now wait for the console's own startup to finish before syncing game names. If your console crashed on boot with 2.1.1, install this and tell me if it still happens.
- **Menu language:** *Automatic* resolves from the console language, including the one set by Console Language.

## Which file?

- `options_menu.hmod`: use this one.
- `options_menu_compat.hmod`: only if another hmod replaces the console's `libstdc++` (e.g. RetroArch 1.8.4 Xtreme SC) and the menu doesn't open with the normal build.
